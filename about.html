ABOUT THIS PROJECT

About the Quiz

Welcome to the Web Technologies Quiz!

This website was created as my synthesis project to demonstrate what I have learned about HTML, CSS, and JavaScript.

Technologies Used

HTML

HTML is used to structure the website, create the quiz questions, and provide answer options.

CSS

CSS is used to style the website with colours, spacing, borders, and buttons.

JavaScript

JavaScript is used to check the answers, calculate the score, and display the quiz results.

Purpose of the Project

The purpose of this project is to create an interactive quiz that allows users to test their knowledge of web technologies.

Users can answer five multiple-choice questions and view their final score and feedback.
